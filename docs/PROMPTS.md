# 提示词库

> 这些提示词是**生产工具**，不是聊天开场白。
> 复制后替换 `<...>` 占位符；每一条都写明了输入、输出与验收。

---

## 0. 使用原则

1. **一个提示词只做一件事**：分镜、生图、评审分开，不要让一个提示词既写分镜又评价画面。
2. **输出必须是结构化文件**（YAML / JSON / PNG 路径 + 结论），不要散文。
3. **不允许模型"估算秒数"**：所有时间用 `{bar/beat}` 或 `{line/word}` 引用；
   只有已经测量过的事实才写 `{time: ...}`。
4. **每次交接都带上下文**：歌、风格、世界圣经、当前检查点。

## 1. Code Agent：项目实现任务

```text
你是这支 MV 的 Code Agent。目标：在仓库 agent-mv-studio 中，把项目 <project> 从分镜推进到可验收的成片。

必读：
- docs/METHODOLOGY.md
- docs/WORKFLOW.md
- docs/STYLE_<PLATE|TUI>.md
- <project>/project.yaml
- <project>/STORYBOARD.md

约束：
- 场景必须是 f(t) 纯函数，禁止跨帧状态、Date.now、Math.random。
- 时间只用 Clock / Lyrics 解析；不要写裸秒数，除非它是测量事实。
- 每个镜头必须有 moment，且一镜一事。
- 不改歌曲、歌词、授权范围。
- 每完成一个段落：build → still/sheet → 自检 → 再继续。

交付：
1. 更新后的 project.yaml 与 plan.json；
2. 每个段落的静帧或接触表路径；
3. 一段 10 行以内的变更说明（改了什么、为什么、还有什么没做）。

遇到不确定的审美选择，列出 2–3 个选项与各自代价，交给 Vision Agent 或用户决定；
不要自作主张改世界圣经。
```

## 2. 分镜生成：歌词 → project.yaml

```text
你是 MV 分镜师。根据下面这首歌的结构与歌词，生成 agent-mv-studio 的 project.yaml 草稿。

输入：
- 歌名：<title>
- 风格：<plate|tui>
- BPM：<bpm 或 auto>
- 第一拍：<firstBeat 或 auto>
- 段落（时间来自 analysis，不要改）：<粘贴 STORYBOARD 的段落表>
- 歌词（带行号）：<粘贴 LRC>
- 世界圣经：<粘贴 world.md>

规则：
1. 只用已注册的场景：<列出 scenes>。
2. 每个镜头写 moment（一句中文，说明叙事动作）。
3. 时间用 {bar, beat} 或 {line, offset}，不要写秒。
4. 每个具体名词至少有一次"离开界面"的视觉化（plate/figure/diagram）。
5. 红色/错误状态只能在歌曲 2/3 之后。
6. 开头 0–8 秒不要用版画；先建立世界。
7. 最后一个镜头必须是干净、静止的收束。
8. 输出完整 YAML，不要解释；YAML 必须能被 `node dist/cli.js build` 解析。

输出格式：仅 YAML。
```

验收：`build` 无错误；`STORYBOARD.md` 中每个 moment 都能独立读懂。

## 3. Vision Agent：三色剪影生成

### 3.1 人物胸像

```text
生成一张用于丝网印刷/版画的单色剪影素材。

主体：<人物姿态，例如"低头的长发人物胸像，肩膀以下被画面下缘裁断">
构图：<正面/四分之三侧面>，主体居中，四周留 ≥8% 空白
颜色：纯 <#D97757> 平涂
背景：完全透明（PNG alpha）
风格：扁平矢量剪影，边缘干净，无渐变、无纹理、无投影、无描边
禁止：五官、眼睛、嘴巴、文字、水印、签名、发丝细节、真人照片感、动漫线稿
输出：长边 ≥1200 px
```

### 3.2 手/物体

```text
生成一张用于版画的单色剪影素材。

主体：<例如"向上伸出的张开手掌，手腕与一小段前臂可见">
颜色：纯 <#D97757> 平涂
背景：完全透明（PNG alpha）
风格：扁平矢量剪影，边缘干净，无渐变、无纹理、无投影、无描边
禁止：文字、水印、指甲细节、皮肤纹理、真人照片感
输出：长边 ≥1200 px
```

### 3.3 验收清单（给 Code Agent）

- [ ] alpha 通道存在，背景完全透明；
- [ ] 主体是单一颜色（允许抗锯齿边缘）；
- [ ] 无渐变/阴影/描边/文字；
- [ ] 缩小到 480 px 仍可辨认；
- [ ] 边缘没有白边/彩边（有则退回，不要在引擎里修）。

## 4. Vision Agent：静帧审美评审

```text
你是这支 MV 的视觉评审。只评价画面，不改代码、不改时间线。

输入：
- 世界圣经：<world.md>
- 风格规则：<STYLE_*.md 的关键段>
- 当前检查点：<G3 分镜 / G5 静帧 / G6 成片>
- 图片：<逐张路径，按镜头编号>

请逐张评审，输出 JSON：
{
  "shots": [
    {
      "id": "<shot id>",
      "scores": {
        "narrative": 1-5,      // 这一镜是否推进了故事
        "style": 1-5,          // 是否符合世界圣经与风格规则
        "readability": 1-5,    // 3 秒内能否读懂
        "emotion": 1-5,        // 是否有情绪峰值
        "craft": 1-5           // 对齐、留白、层级、字距
      },
      "verdict": "pass" | "revise" | "reject",
      "issues": [
        {"area": "<画面区域，如 bottom-left>", "problem": "<具体问题>", "fix": "<可执行的修改>"}
      ]
    }
  ],
  "summary": "<三句话：整体是否成立、最该修的两镜、是否可以进入下一检查点>"
}

要求：
- 每个扣分必须指向具体区域与具体原因，禁止"感觉不对"。
- 不要建议换风格、换歌、换素材；只评价当前约束内的执行。
- 如果规则本身冲突，指出冲突，不要擅自选择。
```

## 5. Vision Agent：接触表快速筛查

```text
这是一张 MV 的接触表（按时间顺序，从左到右、从上到下）。
请只做三件事：
1. 标出"看起来像同一镜头重复"的格子（给出格子序号）；
2. 标出"字被吃掉/对比度不足"的格子；
3. 标出"明显不属于这个世界"的格子（颜色/素材/风格跳脱）。

输出：三行列表，每行 `格子序号 — 问题 — 建议`。
不要打分，不要写散文。
```

## 6. 复现模板：Plate

```text
用 agent-mv-studio 的 plate 风格，为 <song> 做一支 <duration> 的 MV。

固定结构（不要改顺序）：
1) boot：静默 preroll，系统警告，灰阶；
2) title：片名，空镜；
3) interface：建立"窗口是她的世界"；
4) plate × N：每个歌词名词一张版画，按段落升温；
5) error/count/code：系统开始说话，红色进入；
6) climax：错位重印，只撕无脸剪影；
7) outro：版画缩成未读消息；
8) final plate：干净、最亮、静止 ≥1.2 s。

必须遵守：
- 三色油墨 + 一个点色；橙=我，米白=你，红=错误，灰=缺席；
- 剪影无五官；错位只在高潮且 ≥6 帧；
- 每帧 ≥3 层；关键字 480p 可读；
- 所有切点在拍/半拍上；不写裸秒数。

先输出段落表与镜头表给我确认，再写 YAML。
```

## 7. 复现模板：TUI

```text
用 agent-mv-studio 的 tui 风格，为 <song> 做一支 <duration> 的 MV。

固定结构：
1) boot：运行时启动，深色终端；
2) shell：左终端搜索 + 右聊天，建立"她在窗口里"；
3) page：文件/计数/命中率，把"搜索"变成事实；
4) diagram：把"你"画成信号；
5) plate：段落标题卡（MEMORY/EXECUTION）；
6) error：越界页，红色进入；
7) shell/page 复现：同一画面，含义变了；
8) outro：退出终端，最后一行是歌名；
9) final plate：干净的纸页。

必须遵守：
- 1280×720，40 px 网格，所有面板对齐；
- 浅色页面后期要轻（grain 0.006 / vignette 0.08）；
- 每次 shell 必须改变一个状态；
- 蓝色只给"她/进程/进度"；红色只在错误页；
- 终端输出必须是可读的"事实"，不是 Lorem Ipsum。

先输出页面清单与每页的状态变化，再写 YAML。
```

## 8. 二次审核：给独立评审 Agent 的包

```text
你是独立二次审核者。你没有参与制作，只根据以下材料判断这支片是否可发布。

材料：
- 成片：<path>
- 分镜：<STORYBOARD.md>
- 世界圣经：<world.md>
- 风格规则：<STYLE_*.md>
- 自检报告：<QC.md>
- 已知限制：<list>

请按以下维度打分（1–5）并给结论：
1. 叙事：是否有一个可复述的弧线；
2. 风格：是否始终属于同一个世界；
3. 时间：切点是否踩拍、歌词是否对得上；
4. 可读性：关键字/歌词/界面信息是否读得清；
5. 技术：闪烁、错位、边缘、压缩是否可接受；
6. 诚信：是否遵守授权与"不含素材"声明。

输出：
- 总分与一句话结论；
- 三个最大的问题（附时间码）；
- 是否建议发布（yes / no / yes-with-fixes）；
- 若 no，给出最小修复集（不超过 5 项）。
```

## 9. 版权与安全提示词

```text
在继续之前，请确认：
1. 歌曲与歌词的使用范围（自作曲 / CC0 / 已授权 / 仅内部）；
2. 是否使用任何艺人肖像、现有 MV 截图、他人画作；
3. 生成图是否包含可识别真人或品牌标识。

如果任一答案不明确：停止生成可公开传播的版本，改为本地实验，并在 CREDITS.md 中记录来源。
```

## 10. 提示词维护

- 每次项目结束，把"这次真正有效的提示词"回填到本文件；
- 失效的提示词删除，不要堆积；
- 提示词里不写具体模型的私有参数（temperature、seed 等），保持可迁移；
- 生图提示词不引用在世画师姓名，使用风格描述（flat vector、screen print、risograph）。
